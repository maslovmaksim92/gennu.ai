# Proto.ai Documentation

Документация Proto.ai разделена по аудиториям.

- **User Guide** — документация для пользователей Studio: создание сайтов, темы, блоки, AI-редактор, версии, публикация и домены.
- **Admin Guide** — документация для администраторов: пользователи, администраторы, темы, блоки, версии, AI, интеграции и эксплуатация.

Обе части хранятся как Markdown в этом репозитории и предназначены для публикации через GitBook Git Sync.

## GitBook

Рекомендуется создать два GitBook Space, подключённых к одному GitHub-репозиторию и ветке `main`:

- Proto.ai User Guide → `/docs/gitbook/user`
- Proto.ai Admin Guide → `/docs/gitbook/admin`

Так публичную пользовательскую документацию можно публиковать отдельно от административной документации и независимо управлять доступом.
