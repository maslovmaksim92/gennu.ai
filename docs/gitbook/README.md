# Proto.ai Documentation

Документация Proto.ai разделена по аудиториям и по уровням доступа.

- **User Guide** — публичная документация для пользователей Studio: создание сайтов, темы, блоки, AI-редактор, версии, публикация и домены.
- **Admin Guide** — закрытая документация только для администраторов Proto.ai: пользователи, администраторы, темы, блоки, версии, AI, интеграции и эксплуатация.

Обе части хранятся как Markdown в этом репозитории и предназначены для публикации через GitBook Git Sync.

## GitBook

Нужно создать два независимых GitBook Space, подключённых к одному GitHub-репозиторию и ветке `main`:

- Proto.ai User Guide → `/docs/gitbook/user`
- Proto.ai Admin Guide → `/docs/gitbook/admin`

## Access policy

### User Guide

User Guide может быть публичным и доступным без административной авторизации.

### Admin Guide

Admin Guide является **private documentation**.

Обязательные правила:

- доступ только для пользователей с ролью `ADMIN`;
- обычный пользователь с ролью `USER` не должен иметь доступ к Admin Guide;
- ссылка на Admin Guide должна отображаться только внутри Admin application;
- в Studio и публичном Landing ссылка на Admin Guide не показывается;
- знание прямого URL не должно давать доступ к документации;
- доступ должен проверяться механизмом аутентификации/авторизации, а не только скрытием ссылки;
- при потере роли администратора доступ к Admin Guide должен быть отозван.

Если GitBook-тариф поддерживает authenticated access/SSO, Admin Space нужно закрыть этим механизмом и связать доступ с административными аккаунтами Proto.ai. Если доступ GitBook невозможно связать с ролью `ADMIN`, административную документацию нельзя публиковать как общедоступный GitBook Space; в таком случае её следует отдавать через защищённый слой/прокси Admin application.
