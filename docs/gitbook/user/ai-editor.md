# AI-редактор

AI-чат в Studio предназначен для редактирования текущей страницы естественным языком.

Пример запроса:

> Сделай Hero компактнее, добавь после него блок преимуществ и сделай фон светлее.

AI не должен напрямую заменять страницу произвольным HTML/CSS. Запрос преобразуется в разрешённые операции над Page/Block/Theme Schema, проходит валидацию и только затем применяется к preview.

## Безопасность изменений

Для AI-операций предусматриваются history/snapshot и Undo. Разрушительные действия и публикация должны требовать явного подтверждения пользователя.

## Контекст

В AI передаётся только необходимый контекст: текущая страница, тема, выбранный блок, доступные блоки/варианты и разрешённые инструменты.
