# Начало работы

> Пользовательская Studio ещё не реализована. Эта страница фиксирует целевой сценарий и будет обновляться по мере разработки.

## Планируемый сценарий

1. Зарегистрироваться по электронной почте и войти в Proto.ai.
2. Создать новый сайт.
3. Выбрать стартовый шаблон или начать с пустой страницы.
4. Выбрать тему.
5. Добавить и настроить блоки.
6. При необходимости использовать AI-чат для изменений.
7. Проверить preview.
8. Опубликовать сайт.

Пользовательская документация не должна включать административные операции, внутренние интеграционные ключи или управление системными темами/блоками.
