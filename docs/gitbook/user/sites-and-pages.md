# Сайты и страницы

> Раздел описывает запланированный Studio workflow.

## Сайт

Сайт — пользовательский проект, содержащий страницы и закреплённую версию темы.

## Страница

Страница содержит упорядоченные экземпляры блоков. Каждый экземпляр блока хранит собственные данные и настройки и закреплён за конкретной `BlockVersion`.

## Редактирование

Пользователь сможет:

- добавлять блоки;
- менять их порядок;
- редактировать контент и настройки;
- менять доступные варианты блока;
- использовать AI-чат для тех же операций;
- просматривать изменения до сохранения/публикации.

AI должен менять модель страницы через разрешённые структурированные операции, а не вставлять произвольный HTML/CSS напрямую.
