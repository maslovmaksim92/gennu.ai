# Публикация и домены

> Publication Gateway, пользовательская публикация и домены относятся к следующим этапам разработки и пока не реализованы в Admin MVP.

## Планируемая публикация

После подготовки сайта пользователь сможет опубликовать собранный статический результат через Publication Gateway в S3-compatible storage/CDN. Для первой версии инфраструктуры ранее выбран Timeweb.

## Собственный домен

Планируется возможность привязать существующий домен пользователя. Сервис должен проверить владение/контроль домена через DNS-инструкции, затем настроить маршрутизацию и SSL.

## Регистрация домена

В дальнейшем регистрация домена может быть доступна из интерфейса Proto.ai через интеграцию с внешним провайдером. Эта возможность должна оставаться отдельной от основного Page/Theme/Block Engine.
