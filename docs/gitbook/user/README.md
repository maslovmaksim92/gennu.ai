# Proto.ai — Руководство пользователя

Добро пожаловать в пользовательскую документацию Proto.ai.

Proto.ai позволяет собирать сайты из готовых блоков, применять темы и использовать AI-чат для редактирования страницы. Эта часть продукта будет реализовываться после Admin MVP, поэтому документация описывает целевой пользовательский workflow и будет уточняться вместе со Studio.

## Основные возможности

- создание и управление сайтами;
- сборка страниц из блоков;
- выбор и настройка темы;
- AI-редактирование страницы через структурированные команды;
- безопасное обновление тем и блоков по желанию пользователя;
- публикация сайта;
- подключение собственного домена и SSL.

## Версионность

Сайт всегда использует конкретную версию темы, а каждый блок — конкретную версию блока. Новая версия, опубликованная администратором, не изменяет существующий сайт автоматически.

Когда обновление доступно, пользователь должен получить возможность посмотреть изменения, выполнить preview и только после подтверждения перейти на новую версию. Для обновлений со сменой schema выполняется migration, а предыдущая версия/снимок сохраняется для rollback.
