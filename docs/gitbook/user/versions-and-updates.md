# Версии и обновления

Proto.ai использует opt-in версионность тем и блоков.

## Главное правило

Новая версия темы или блока никогда не применяется к существующему сайту автоматически.

Сайт хранит точный `themeVersionId`, а экземпляр блока — точный `blockVersionId`. Поэтому публикация администратором новой версии не меняет текущий дизайн пользователя.

## Когда доступно обновление

Studio должна показать текущую и новую версии, changelog и действие Preview.

Планируемый flow:

1. Пользователь выбирает Preview update.
2. Система создаёт snapshot текущего состояния.
3. Если schema изменилась, запускается предусмотренная migration.
4. Результат валидируется и показывается в preview.
5. Только после подтверждения меняется закреплённый version ID.
6. Предыдущий snapshot остаётся доступен для rollback.

Даже PATCH-обновления являются добровольными для существующих сайтов.
