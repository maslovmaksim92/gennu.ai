# AI Assistant

Admin использует единый AI backend в разных режимах контекста.

## Общий Admin Assistant

Используется для административной помощи, анализа доступной через разрешённые tools информации и подготовки контента.

## Theme/Block Editor

В редакторе темы или блока AI получает ограниченный контекст редактируемого объекта и набор разрешённых операций. Он не должен иметь прямой произвольный доступ к PostgreSQL и не должен обходить versioning rules.

AI не может изменять `PUBLISHED` schema. Если администратор хочет изменить опубликованный объект, сначала создаётся новая draft-версия.

## Секреты и расходы

OpenAI API key хранится только на backend в настройках интеграции/секретах. Frontend ключ не получает. В дальнейшем Admin должен показывать usage, estimated cost и квоты AI по пользователям/workspaces.
