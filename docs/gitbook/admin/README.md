# Proto.ai — Руководство администратора

> **Private / Admin only.** Эта документация доступна только пользователям Proto.ai с ролью `ADMIN`.

Эта документация описывает текущий Admin MVP и целевые административные workflows.

## Политика доступа

Admin Guide не является публичной документацией.

- доступ разрешён только после аутентификации администратора;
- роль пользователя должна быть `ADMIN`;
- пользователи с ролью `USER` не имеют доступа;
- ссылка на документацию отображается только в Admin application;
- прямой URL не должен обходить авторизацию;
- при блокировке администратора или снятии роли доступ должен быть немедленно отозван.

Скрытие ссылки в интерфейсе не считается защитой. Доступ должен ограничиваться на уровне GitBook authenticated access/SSO либо через защищённый gateway Admin application.

## Текущие области Admin

- вход администратора;
- управление администраторами и приглашениями;
- управление пользователями;
- системные темы;
- системные блоки;
- AI Assistant и AI в редакторах тем/блоков;
- внешние интеграции;
- аудит и эксплуатационные настройки по мере развития продукта.

## Важное правило версий

Опубликованные `ThemeVersion` и `BlockVersion` являются immutable artifacts. Нельзя изменить опубликованную schema так, чтобы существующие сайты пользователей поменялись. Для изменения создаётся новая draft-версия и публикуется отдельно.
