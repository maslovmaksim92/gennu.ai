# Версионность тем и блоков

## Инвариант

`PUBLISHED ThemeVersion` и `PUBLISHED BlockVersion` — неизменяемые артефакты.

Lifecycle:

`DRAFT -> PUBLISHED -> DEPRECATED`

## SemVer

Версии имеют формат `MAJOR.MINOR.PATCH`, например `1.0.0`, `1.1.0`, `2.0.0`.

- PATCH — исправление без намеренного изменения контракта;
- MINOR — совместимое расширение;
- MAJOR — breaking change/новый контракт.

Независимо от типа версии существующие пользовательские сайты не обновляются автоматически.

## Migration

Если новая schema требует преобразования данных, версия может описывать migration. Она выполняется только в пользовательском upgrade flow после создания snapshot и до подтверждения перехода на новую версию.

## Deprecated

Deprecated-версия остаётся доступной для существующих ссылок. Нельзя удалять version artifact, пока он нужен пользовательским сайтам/блокам.
