# Администраторы и пользователи

## Администраторы

Администратор может приглашать другого администратора. Приглашение хранится отдельно и имеет lifecycle `PENDING`, `ACCEPTED`, `EXPIRED` или `CANCELLED`.

Административные действия должны выполняться только через защищённый Admin API и попадать в Audit Log по мере расширения аудита.

## Пользователи

Admin должен показывать зарегистрированных пользователей и позволять выполнять разрешённые административные операции, например просмотр статуса и блокировку/разблокировку аккаунта.

В дальнейшем из карточки пользователя администратор должен иметь возможность перейти к его сайтам и диагностической информации, не меняя пользовательский контент без явной административной операции.
