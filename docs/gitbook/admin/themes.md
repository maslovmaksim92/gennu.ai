# Темы

Системная тема состоит из `Theme` (identity/metadata) и набора `ThemeVersion`.

## Создание

При создании темы формируется первая версия `1.0.0` со статусом `DRAFT`. Draft можно редактировать, проверять через preview и дорабатывать с помощью AI-чата.

## Публикация

После публикации версия становится immutable. Изменять её schema нельзя. Следующие изменения выполняются через создание новой версии, например `1.1.0` или `2.0.0`.

## AI

В Theme Editor администратор может описывать изменения естественным языком. AI должен преобразовывать запрос в структурированные изменения Theme Schema, которые проходят валидацию и показываются в preview.

## Удаление

Тему с опубликованной историей нельзя удалять как обычный draft. Старые опубликованные версии сохраняются для сайтов, которые на них закреплены; устаревшую версию можно пометить `DEPRECATED`.
