# Внешние интеграции

Admin содержит отдельный раздел внешних сервисов. У каждого провайдера могут быть собственные config, secret, status, health/error information и административные действия.

## OpenAI

Используется AI Gateway/Assistant. API key хранится на backend и не передаётся Angular-клиенту.

## Timeweb

Timeweb выбран для первой версии инфраструктуры публикаций. В дальнейшем административный интерфейс должен позволять настраивать интеграцию, видеть доступные финансовые/usage данные провайдера и выполнять поддерживаемые API операции.

## Общие правила

- секреты не коммитятся в Git;
- секретные значения хранятся в зашифрованном виде или secret manager;
- frontend получает только безопасную конфигурацию/статус;
- ошибки внешнего сервиса логируются без утечки секретов;
- provider-specific код изолируется за integration/provider abstraction.
