# Блоки

Системный блок состоит из `BlockDefinition` и набора `BlockVersion`.

## Создание

Новый блок получает `1.0.0 DRAFT`. Draft содержит schema, defaults и при необходимости migration metadata.

## Редактор

Администратор должен иметь визуальный preview, свойства блока и AI-чат. AI может помогать менять schema/defaults и создавать варианты, но изменения должны оставаться структурированными и валидируемыми.

## Публикация

Опубликованный `BlockVersion` не редактируется. Для изменений создаётся следующая версия. Это гарантирует, что уже существующие экземпляры блока у пользователей не изменятся.

## Использование

Будущий `BlockInstance` хранит точный `blockVersionId`. Поэтому обновление definition в Admin не переключает пользовательский экземпляр на latest автоматически.
